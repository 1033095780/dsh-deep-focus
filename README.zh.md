# dsh-deep-focus

一个给 DeepSeek Harness 用的专注助手：在 DSH 运行期间统计整机真实使用时长，默认执行**每日 3 小时上限**与**连续 30 分钟上限**（到点强制休息 **10 分钟**），并默认**一次只保留一个会话**——全部只在 DSH 内进行，绝不拦截任何工具调用。

[English](README.md) | 简体中文

## 为什么

写代码的 agent 让同时开五个对话变得毫不费力。这对吞吐量是好事，对「把一件事做完」是灾难，也很容易拖成一天 12 小时。

`dsh-deep-focus` 用温和且诚实的方式划出一条边界：

- 统计的是**DSH 运行期间的整机活跃时长**，而不只是你盯着 DSH 的时间；
- **连续使用 30 分钟**到点后，用全屏的**休息 10 分钟**界面把工作停下来；
- **每日活跃 3 小时**用完后，DSH 内出现灰色遮罩，展示今日各应用明细，并提供一个小小的「再使用 20 分钟」；
- 默认**一次只保留一个会话**：任一会话的 agent 在运行时，侧栏里其它文件夹与会话会被临时隐藏，等它结束自动恢复。

它绝不拦截工具调用、绝不打断其它会话的 agent，也绝不在 DSH 之外强制执行任何东西。具体边界见[纯插件能力边界](#纯插件能力边界)。

## 功能

| 功能 | 说明 |
| --- | --- |
| **专注助手面板** | 侧栏「插件」下方一个入口：概览（今日用量、连续计时、各应用明细、近 7 天趋势）、设置、启用/暂停开关。 |
| **每日上限（默认 3 小时）** | DSH 运行期间的整机活跃时长达到上限后，DSH 内出现灰色遮罩：今日总时长、各应用明细、「再使用 20 分钟」（时长与每日次数可配）以及安静的「今天到此为止」。 |
| **连续上限 → 强制休息** | 连续使用 30 分钟 → DSH 内全屏**休息 10 分钟**，倒计时可见；休息时间**不计入**每日上限。 |
| **右上角倒计时** | DSH 窗口右上角常驻小胶囊：连续剩余时间、休息剩余时间，或「今日已用完」。 |
| **一次只用一个会话** | 默认开启。任一根会话的 agent 在运行时，侧栏临时隐藏其它文件夹与会话，结束后立即恢复。正在运行的 agent 完全不受影响。 |
| **按软件使用统计** | DSH 运行期间采样前台应用：DeepSeek Harness、浏览器、QQ、微信、VS Code、终端等。只记录应用名与时长。 |
| **本地、私密** | 数据只存在 `$DSH_HOME/plugin-data/dsh-deep-focus/`；不联网、无遥测、无账号。 |

本版本**没有番茄钟**——用上面这套使用规则取代了工作/休息循环。

## 安装

环境要求：

- DeepSeek Harness **0.2.2-rc.1**（已实测；`engines.dsh` 同时接受 `0.2.0-rc.2` 与 `0.2.1-rc.2`）
- 桌面版 DSH（浏览器端 UI 运行在 DSH Web GUI 中）

**在 DSH 桌面应用里安装**

1. 打开 **插件** 页，搜索 `dsh-deep-focus`。
2. 安装并启用该组合包；从插件页安装默认就是启用状态。
3. 如果界面没有立刻出现插件，重启一次 DSH。

**用命令行安装**

```bash
dsh plugin --profile desktop add dsh-deep-focus
```

插件直接发布源码：没有构建步骤，也没有需要安装的运行时依赖。禁用或卸载插件会立刻移除所有界面元素、恢复侧栏，并停止全部统计。

## 快速开始

1. 打开侧栏「插件」下方的**专注助手**（英文为 Focus assistant）。
2. 查看今日用量与各应用明细；近 7 天趋势也在同一页。
3. 默认规则已经生效：每日 3 小时、连续 30 分钟 → 休息 10 分钟。
4. 留意 DSH 窗口**右上角的倒计时**：接近连续上限时会变成警示色，休息时显示休息倒计时。
5. 用助手面板里的开关可以暂停限制（统计继续），同一页的设置可以修改任何上限。

## 配置

所有运行期设置都在**专注助手**面板中。下表由 `node scripts/config-table.mjs` 从 `src/shared/contract.js` 生成。

<!-- config-table:start -->
| 配置项 | 默认值 | 单位 | 说明 |
| --- | ---: | ---: | --- |
| `limits.dailyMinutes` | 180 | 分钟 | DSH 运行期间整机活跃时长的每日上限；0 = 不限制。 |
| `limits.continuousMinutes` | 30 | 分钟 | 触发强制休息的连续使用时长的上限；0 = 不强制休息。 |
| `limits.restMinutes` | 10 | 分钟 | 强制休息时长。休息时间不计入每日上限。 |
| `limits.extendMinutes` | 20 | 分钟 | 点击一次「再使用 20 分钟」增加的时长。 |
| `limits.dailyExtendLimit` | 2 | 次 | 每日可延长次数；0 = 不允许延长。 |
| `assistant.enabled` | 开 | — | 统计并执行限制；关闭后只做统计，不做任何限制。 |
| `assistant.soloSession` | 开 | — | 有根会话在运行时，UI 上一次只保留一个会话。 |
| `assistant.hideOtherSessions` | 开 | — | 有会话在运行时临时隐藏其它文件夹与会话。 |
| `assistant.showCountdown` | 开 | — | 在 DSH 窗口右上角显示倒计时胶囊。 |
| `alerts.sound` | 开 | — | 休息与完成提醒时播放短提示音。 |
| `alerts.volume` | 0.6 | 0–1 | 提示音音量。 |
| `alerts.quietHoursStart` | null | HH:MM | 静音时段的开始时间（该时段内不播放提示音）；null = 关闭。 |
| `alerts.quietHoursEnd` | null | HH:MM | 静音时段的结束时间；null = 关闭。 |
| `alerts.taskDone` | 开 | — | agent 任务完成时显示 toast 并播放提示音。 |
| `usage.sampleSeconds` | 5 | 秒 | 前台应用与空闲时长的采样间隔。 |
| `usage.idleThresholdSeconds` | 60 | 秒 | 空闲时长低于此值算作活跃。 |
| `usage.retentionDays` | 30 | 天 | 本地使用记录保留天数。 |
| `usage.trackApps` | 开 | — | 记录前台应用（只存应用名与时长，不记录窗口标题）。 |

## 规则是怎么工作的

- **什么算使用：** 只有在最近有键鼠输入（`usage.idleThresholdSeconds`）且 DSH 正在运行时才计时；统计的是整机活跃，而不是 DSH 窗口是否在前台。
- **连续使用**在你活跃时累加。达到 `limits.continuousMinutes`（默认 30）时，助手**立即**开始一段 `limits.restMinutes`（默认 10）的强制休息：休息屏出现，活跃计时停止，休息时间不计入每日总时长。休息结束后连续计时从零开始。
- **每日使用**按同样的活跃时长累加。达到 `limits.dailyMinutes`（默认 180）后，DSH 内出现灰色遮罩：
  - **「再使用 20 分钟」**立即增加 `limits.extendMinutes`（默认 20），每天最多 `limits.dailyExtendLimit` 次（默认 2，`0` = 不允许延长）。延长时间用完后遮罩会再次出现。
  - **「今天到此为止」**只在该浏览器里把今天的遮罩收起，是一份尽力而为的确认，不是强制手段。
- **每日重置：** 本地时间午夜清零。
- **右上角倒计时：** 连续剩余时间、休息剩余时间，或「今日已用完」；可用 `assistant.showCountdown` 关闭。
- **暂停：** 关闭 `assistant.enabled`（面板开关）后，一切照常统计，但不再执行任何限制——没有休息屏，也没有每日遮罩。

## 一次只用一个会话

- **默认开启**（`assistant.soloSession` + `assistant.hideOtherSessions`）。任一根会话的 agent 在运行时，侧栏临时**隐藏**其它文件夹与会话，并显示一条柔和的说明横幅。
- 正在运行的会话完全可用，其它后台 agent 也会照常跑完——这是 UI 层面的引导，**不是锁**：不会拦截任何工具调用，也不会打断任何 agent。
- 没有会话在运行时，侧栏会自动恢复；禁用插件或与 Host 失联时也会立即恢复。

## 专注助手面板与使用统计

- **入口：** 侧栏「插件」下方——「专注助手」/ Focus assistant。打开后是一页三部分：概览、设置、启用/暂停开关。
- **概览：** 今日活跃时长与每日上限、连续时长与连续上限、休息状态、各应用明细（前 8 个，名称 + mm:ss + 进度条）以及近 7 天趋势。
- **设置：** 上方配置表里的所有上限与开关，标签里带单位。
- **按软件统计**每隔几秒采样前台应用，只保存**应用名与时长**——不记录窗口标题、按键内容或 URL。关闭 `usage.trackApps` 可只保留总时长。Windows 的前台识别是一等公民；macOS/Linux 为尽力而为。

## 纯插件能力边界

本版本**只是 DSH 插件**。它做不到桌面守护程序能做的事，README 如实写清楚：它**不能把 DSH 拉到前台**，**不能阻止其它应用**（休息时你仍然可以切走），也**不能统计 DSH 关闭时的使用**。覆盖这些场景的桌面守护程序属于后续可选阶段，不在本版本内。

| 想要的行为 | 本版本 | 原因 |
| --- | --- | --- |
| 在 DSH 内统计用量、显示倒计时 | ✅ 可以 | 运行在 DSH Host 与 Web GUI 中 |
| DSH 内的灰色每日遮罩与各应用明细 | ✅ 可以 | 在 DSH 内渲染 |
| 在 DSH 内强制显示休息屏 | ✅ 可以 | 在 DSH 内渲染 |
| 一次只用一个会话（侧栏隐藏） | ✅ 可以（仅 UI） | 绝不拦截工具或 agent |
| **把 DSH 窗口拉到最前** | ❌ 不能 | 需要桌面窗口/系统 API |
| **休息时阻止使用其它应用** | ❌ 不能 | 需要全局置顶遮罩 / 输入钩子 |
| **DSH 关闭时继续统计或限制** | ❌ 不能 | 插件运行在 DSH 进程内 |
| **在 DSH 窗口之外显示倒计时** | ❌ 不能 | 只能画在 DSH 内部 |

配套的桌面守护程序（托盘程序：全局前台采样、置顶休息遮罩、把 DSH 拉到前台、DSH 关闭时继续计时）是**后续可选阶段，v0.3 不包含**。当前版本刻意用「零安装的纯插件体验」换取这部分全局能力。

## 数据与隐私

- 完全本地。数据位于 **`$DSH_HOME/plugin-data/dsh-deep-focus/`**（`$DSH_HOME` 默认是 `~/.dsh`）：`settings.json`（权限 `0600`）、`limits.json`，以及按天的 `usage/YYYY-MM-DD.jsonl`。
- 采样器读取空闲时长与**前台应用名称**（Windows 上取前台窗口所属进程；不读取标题文本）。它不会读取按键内容、窗口标题、应用内容、截图或剪贴板。
- **不联网、无遥测、无账号、无第三方服务。**
- 休息时间不计入每日总时长；使用记录按 `usage.retentionDays`（默认 30 天）清理。删除数据目录即可清除全部数据。

完整说明见 [docs/privacy.md](docs/privacy.md)。

## 已知限制

- 纯插件：**没有全局强制力**——从不阻止你切到别的应用，也不会把 DSH 拉到前台。见上方能力边界。
- **只在 DSH 运行期间采样**；DSH 关闭时的时长不统计，界面也无法展示。
- **Windows 是首选平台。** macOS/Linux 的前台应用识别已实现，但属于尽力而为。
- 前台统计按可执行文件粒度：一些应用共享进程名，未知程序会以原始名称出现。
- 单会话模式只是隐藏侧栏条目，是视觉引导而非硬拦截，后台 agent 照常工作。
- 「今天到此为止」是按天、按浏览器保存的确认；换浏览器或清除站点数据后遮罩可能再次出现。
- 没有跨设备同步、没有报告。

## 开发

```bash
node --check src/index.js src/client.js   # 语法检查
npm test                                  # node --test（Host 纯逻辑单测）
node scripts/verify.mjs                   # 离线打包冒烟检查
```

仓库结构：

```text
src/
├── index.js          # Host 入口：Config / inject / apply
├── host/             # 采样、按应用统计、限额/休息状态机、事件、API
├── client.js         # 自包含的浏览器端（助手面板、倒计时、遮罩、设置页）
├── shared/contract.js# 通信契约 + DEFAULT_SETTINGS（默认值唯一来源）
├── locale/           # 中英文 meta.title / meta.description
└── icon.svg          # 插件列表图标
cordis.patch.yml      # 插入 Host 行的组合包 patch
scripts/verify.mjs    # CI 使用的离线打包检查
docs/                 # 设计、隐私、发布文档
```

运行这些检查不需要安装依赖。架构与 API 契约见 [docs/design.md](docs/design.md)。
