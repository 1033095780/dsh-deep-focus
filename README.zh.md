# dsh-deep-focus

一个给 DeepSeek Harness 用的专注助手：**双环小组件**展示今日用量与连续计时（点击可暂停/继续），**自动休息**在持续空闲 60 秒后暂停，**每日 3 小时上限**与**连续 30 分钟上限**管住一天，**一次只用一个会话**让侧栏保持专注——全部只在 DSH 内进行，绝不拦截任何工具调用。

[English](README.md) | 简体中文

## 功能

| 功能 | 说明 |
| --- | --- |
| 双环小组件 | **两等宽列**，每个环**中间显示数值**（今日：分钟；连续：mm:ss），下方居中显示「今日已用」/「连续使用」标题，连续时钟**每秒平滑走动**。**可拖动到任意位置**——真正拖动不会触发暂停/继续，轻点仍然是暂停/继续。位置用 `localStorage` 记住、刷新后保留，并会自动限制在窗口内；默认仍在右上角。 |
| 自动休息 | 键鼠持续空闲达到 `usage.autoPauseSeconds`（默认 60 秒）后显示暂停卡片；约 0.6 秒的稳定延迟只用于这种**自动**暂停，避免闪烁。点击双环暂停会**立即**显示卡片。**任何暂停都会在你动键鼠后立即恢复**：在 DSH 内客户端会在第一次输入时直接 `POST /resume`，几乎无延迟（不必等约 5 秒采样）；在其它软件里的活动仍由整机采样捕获，最长约 5 秒。 |
| 每日上限 | 统计 DSH 运行期间的整机活跃；达到 180 分钟出现今日用量卡片（「再使用 20 分钟」/「跳过」）。若 DSH 在后台，还会尝试 `window.focus()` + 系统通知把你拉回来。 |
| 连续上限 | 连续使用 30 分钟 → 在同一张卡片上休息 10 分钟；休息时间不计入每日总量。**连续用时在任何暂停/休息期间会逐渐衰减，而不是立即清零**——约 `limits.restMinutes` 的恢复时间即可清空（例：连续 20 分钟 → 约 10 分钟休息 → 0，速率 `continuousMinutes / restMinutes`）；短暂停只按比例减少，恢复后从剩余值继续。 |
| 一次只用一个会话 | 固定到**唯一的主会话（primary）**——最近开始运行的那个会话。其它所有行（**包括正在运行的其它会话**）都置灰且不可点击；UI 自动跳回主会话。运行集合变空后，置灰状态会**保持约 1.5 秒**再恢复，不再闪烁。不隐藏任何东西。 |
| 离开提示音 | 只有**所有正在运行的会话全部结束**（运行集合从非空变为空）且你不在电脑前时才响；只完成了一部分会话不会响。响铃直到你回来动键鼠，最多约 2 分钟。 |
| 共用「今日用量」卡片 | 自动暂停、强制休息与每日上限屏都使用**同一张今日用量卡片**（标题/原因 + 今日总计 + 各应用明细），只有标题与按钮不同。 |
| 按应用统计 + 助手面板 | 侧栏入口：概览、近 7 天趋势、精简设置、启用/暂停开关。 |

## 安装

需要 DeepSeek Harness `0.2.2-rc.1`（同时接受 `0.2.0-rc.2` / `0.2.1-rc.2`）与桌面版 DSH。本项目**不发布到 npm**——请从仓库或本地目录安装。

1. 在插件页添加仓库作为安装源（或使用下面的命令），然后启用该组合包。
2. `dsh plugin --profile desktop add https://github.com/1033095780/dsh-deep-focus`
3. 本地目录：`dsh plugin --profile desktop add /absolute/path/to/dsh-deep-focus`。

没有构建步骤，也没有运行时依赖。禁用或卸载会立刻移除所有界面并停止统计。

## 快速开始

1. 打开侧栏「插件」下方的**专注助手**入口。
2. 双环以两等宽列展示今日与连续进度，每个环中间都有数值。点击卡片可暂停——暂停卡片立即出现；在 DSH 内动一下键鼠就几乎立刻恢复（在其它软件里操作则最长约 5 秒内恢复）。键鼠空闲 60 秒也会自动暂停，同样是动键鼠恢复。
3. 连续使用 30 分钟时出现 10 分钟休息屏（共用今日用量卡片 + 「跳过休息」）。
4. 每日使用 3 小时后，灰色遮罩只有「再使用 20 分钟」与「跳过」两个操作（跳过只收起今天的提醒）。
5. 用面板开关可暂停限制；精简设置修改常用上限。

## 规则说明

- **什么算使用：** DSH 运行期间的整机活跃时长；只有最近有键鼠输入（`usage.idleThresholdSeconds`）的采样才计入。
- **每日上限：** 默认 `limits.dailyMinutes` 180。到点后出现共用的今日用量卡片；「再使用 20 分钟」立即增加 `limits.extendMinutes`（20），默认每日不限次数（`limits.dailyExtendLimit` 0 = 不限，正数才是上限）。「跳过」只在该浏览器收起今天的提醒，不续期。如果到点时窗口在后台，插件会尝试 `window.focus()` 并发送一条系统通知（点击可回到 DSH），同时响一次提示音——这只是尽力而为：纯插件**无法强制操作系统把 DSH 切到前台**。
- **连续休息 / 衰减：** 达到 `limits.continuousMinutes`（30）时在同一张今日用量卡片上开始 `limits.restMinutes`（10）的休息；只有休息时间到**且你回来**才结束，也可以按「跳过休息」。暂停（手动或自动）与休息都是**恢复时间**：连续计时会**逐渐衰减**而不是立即清零，速率为每分钟 `continuousMinutes / restMinutes`（默认 30/10 → 休息 1 分钟减 3 分钟连续用时；20/10 时连续 20 分钟 → 约 10 分钟休息 → 0）。短暂停只按比例减少，恢复后从剩余值继续——点一下不会清零。跨天、关闭助手以及无效/睡眠采样间隔仍会清零。休息时间不计入每日总量。
- **统一界面：** 空闲自动暂停、手动暂停、强制休息与每日上限都使用同一张今日用量卡片，只是标题与操作不同——不再有单独的纯灰暂停层。
- **移动计时器：** 按住双环卡片用鼠标或手指**拖动**——移动超过几个像素就变成拖动并抑制暂停点击，普通点击/轻点仍然是暂停/继续。位置保存在 `localStorage`，刷新后保留；拖动和窗口缩放时都会自动限制在窗口内，默认位置仍是右上角。
- **自动休息 / 暂停：** 键鼠持续空闲达到 `usage.autoPauseSeconds`（60，`0` = 关闭）后显示暂停卡片；约 0.6 秒的稳定延迟只用于**自动**暂停，避免单个陈旧采样造成闪烁；此前的活动会重置空闲计数。**点击双环小组件会立即暂停**（`POST /pause`）并立刻显示卡片——不使用 0.6 秒延迟。**任何暂停都会在检测到键鼠活动后恢复**：在 DSH 内客户端会在第一次输入（经短暂防抖）后直接 `POST /resume`，几乎立即恢复，不必等约 5 秒采样；在其它软件里的活动仍由整机采样恢复，最长约 5 秒。卡片显示期间阻断 DSH 界面交互，恢复后立即消失（「继续计时」/Enter/Space/Escape 仍可显式恢复）。
- **一次只用一个会话：** 只保留一个**主会话（primary）**——最近开始运行的那个根会话（`/state.solo.primary`）。UI 自动跳回它；其它所有会话与文件夹行、**包括正在运行的其它会话**，都置灰且不可点击，显示中的非主会话会被遮罩。运行集合变空后，置灰状态会保持约 1.5 秒再恢复，短暂的空中采样不会造成闪烁。后台 agent 照常运行，不拦截任何工具，也不隐藏任何东西。
- **离开提示音：** 只有**所有正在运行的会话全部结束**（root 运行集合从非空变为空）、且你不在电脑前（窗口失焦/隐藏，或整机空闲达到 `alerts.awayIdleSeconds`）时才响；多个会话只完成一部分不会响，子代理/队友回合也不会触发。提示音按 `alerts.repeatIntervalMs` 重复，直到你动键鼠，最多约 2 分钟（`alerts.repeatUntilActive` 可关闭重复）。
- **关闭助手：** 只统计，不显示双环、不休息、不弹遮罩。

## 使用面板

侧栏「专注助手」：今日 vs 每日上限、连续 vs 连续上限、休息状态、各应用明细（前 8 + 近 7 天趋势）、启用/暂停开关，以及右对齐保存/放弃按钮的精简设置。只记录前台应用名与时长——不记录窗口标题、按键内容，不联网。

## 配置

助手页面只暴露 **8 个**设置：每日上限、连续上限、休息时长、续期时长、空闲自动休息秒数、提示音、统计开关，以及「专注时只允许一个对话」（`assistant.soloSession`，控制自动跳回 + 置灰 + 不可点击的单会话模式）。其余配置（续期次数上限、静音时段、离开重复提示音、采样间隔、数据保留、双环开关等）仍在 settings JSON 与插件 API 中，只是**不在界面显示**。

<!-- config-table:start -->
| 配置项 | 默认值 | 单位 | 说明 |
| --- | ---: | ---: | --- |
| `limits.dailyMinutes` | 180 | 分钟 | DSH 运行期间整机活跃时长的每日上限；0 = 不限制。 |
| `limits.continuousMinutes` | 30 | 分钟 | 触发强制休息的连续使用时长的上限；0 = 不强制休息。 |
| `limits.restMinutes` | 10 | 分钟 | 强制休息时长。休息时间不计入每日上限。 |
| `limits.extendMinutes` | 20 | 分钟 | 点击一次「再使用 20 分钟」增加的时长。 |
| `limits.dailyExtendLimit` | 0 | 次 | 每日可续期次数；0 = 不限次数，正数才是每日上限。 |
| `assistant.enabled` | 开 | — | 统计并执行限制；关闭后只做统计，不做任何限制。 |
| `assistant.soloSession` | 开 | — | 有根会话在运行时把 UI 固定到唯一主会话。 |
| `assistant.hideOtherSessions` | 开 | — | 有主会话在运行时把其它会话与工作区文件夹行置灰（可见但不可点击）。 |
| `assistant.showRings` | 开 | — | 在 DSH 右上角显示悬浮双环小组件。 |
| `alerts.sound` | 开 | — | 休息、暂停与完成提醒时播放短提示音。 |
| `alerts.volume` | 0.6 | 0–1 | 提示音音量。 |
| `alerts.quietHoursStart` | null | HH:MM | 静音时段的开始时间（该时段内不播放提示音）；null = 关闭。 |
| `alerts.quietHoursEnd` | null | HH:MM | 静音时段的结束时间；null = 关闭。 |
| `alerts.awayIdleSeconds` | 30 | 秒 | 空闲达到此时长即视为离开（决定完成提示音是否响起）。 |
| `alerts.repeatUntilActive` | 开 | — | 离开期间重复播放完成提示音，直到你回来操作。 |
| `alerts.repeatIntervalMs` | 1000 | 毫秒 | 离开期间提示音的重复间隔（限制在 500–10000 毫秒）。 |
| `usage.sampleSeconds` | 5 | 秒 | 前台应用与空闲时长的采样间隔。 |
| `usage.idleThresholdSeconds` | 60 | 秒 | 空闲时长低于此值算作活跃。 |
| `usage.retentionDays` | 30 | 天 | 本地使用记录保留天数。 |
| `usage.trackApps` | 开 | — | 记录前台应用（只存应用名与时长，不记录窗口标题）。 |
| `usage.autoPauseSeconds` | 60 | 秒 | 键鼠空闲达到此时长后自动暂停计时；0 = 关闭。 |

> 未特别注明时时间单位为分钟。默认值即已确认的产品规则：每日上限 3 小时、连续使用 30 分钟后强制休息 10 分钟、默认不限次数的 20 分钟续期（设置正数才会限制次数），完成提示音只在你离开时重复。助手绝不拦截工具，限制只在 DSH 内生效（见下方能力边界）。

## 数据与隐私

- 完全本地：`$DSH_HOME/plugin-data/dsh-deep-focus/`（`settings.json` 权限 0600、`limits.json`、按天 `usage/YYYY-MM-DD.jsonl`）。不联网、无遥测、无账号。
- 采样器只读取空闲时长与前台应用的进程名；自动休息与离开提示音复用同一信号，不新增任何数据。
- 只保存应用名与时长。休息时间不计入每日总量；记录按 `usage.retentionDays`（30 天）清理。删除数据目录即可清除全部数据。

完整说明见 [docs/privacy.md](docs/privacy.md)。

## 纯插件能力边界

它不能把 DSH 拉到前台、不能阻止其它应用、也不能在 DSH 关闭时统计；每日上限到点只会**尝试** `window.focus()` + 系统通知，操作系统可能忽略两者。休息的视觉只覆盖 DSH 窗口。覆盖这些场景的桌面守护程序属于后续可选阶段，不在本版本内。

| DSH 内可做 | 做不到 |
| --- | --- |
| 用量统计、双环、统一的暂停/休息/每日卡片、自动跳回侧栏 | 强制操作系统前台（focus/通知只是尽力而为）、阻止其它应用、关闭时统计、DSH 外绘制 |

## 开发

```bash
node --check src/index.js src/client.js   # 语法
node --test                               # Host 单测
node scripts/verify.mjs                  # 离线打包检查
node scripts/e2e.mjs http://127.0.0.1:<port>/plugins/dsh-deep-focus/api  # 在线 API 冒烟
```

`scripts/e2e.mjs` 通过 HTTP 验证运行中的插件（state、apps、settings、rest/extend/pause 等路径），并恢复它改动过的设置。
