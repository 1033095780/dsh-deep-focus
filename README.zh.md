# dsh-deep-focus

一个只做一件事的 DeepSeek Harness 组合插件（仓库：
<https://github.com/1033095780/dsh-deep-focus>）：当你在某个会话里**发消息后**，界面会
**锁定**在该会话，直到它**以及它启动的全部子代理/子会话都完全结束**。随后自动解锁：弹出
一条本机**电脑通知**「会话已完成」与约 5 秒的页面横幅；如果已配置，还会给你发一条以 `[+] `
开头的**钉钉完成通知**。遮罩上的「跳过」按钮可以立即解锁，且不会提醒。

## 功能说明

1. 你在某个会话里发送消息。
2. 全屏遮罩盖住 DSH，显示「任务进行中」、会话标题与已过时间；遮罩期间其它会话不可用。
3. 该会话本轮**以及它启动的所有子代理/子会话**都结束后，遮罩自动消失。
4. 自动解锁时还会弹出一条本机**电脑通知**「会话已完成」（浏览器/桌面通知，best-effort），并在
   页面内显示约 5 秒的横幅；点击通知会回到 DSH。
5. 若配置了钉钉，会向你的钉钉机器人发送一条文本消息：
   `[+] 会话已完成：<标题>，用时 <n> 分钟，完成时间 HH:MM`
   （时间取自宿主时钟；token 不会离开你的电脑）。

只完成一部分不会解锁：只要还有子会话在工作，遮罩就一直保留。模型/网络报错同样会结束本轮
并解锁。点击「跳过」解锁时不会弹电脑通知、横幅或钉钉消息。

## 为什么需要它

长时间运行 agent 时人很容易离开；离开期间又很容易在别的会话里误开新任务。这个插件让一个
会话在整个任务树完成之前成为唯一可用的会话，完成后再通过钉钉提醒你回来。

## 环境要求

- DeepSeek Harness `0.2.2-rc.1`（同时接受 `0.2.0-rc.2` / `0.2.1-rc.2`），桌面版安装。
- 只有开发时需要 Node 20+；插件以源码形式分发，没有构建步骤。
- 如需完成通知：一个钉钉群机器人。

## 安装

本项目**不发布到 npm**。请从仓库或本地目录安装：

```bash
dsh plugin --profile desktop add https://github.com/1033095780/dsh-deep-focus
# 或本地目录
dsh plugin --profile desktop add /absolute/path/to/dsh-deep-focus
```

没有运行时依赖，也没有构建步骤；禁用或卸载会立即移除遮罩与设置页。

## 启用

打开 **插件** 页启用该组合包；如果下一次发消息时没有出现遮罩，重载/重启一次 DSH 窗口。

## 设置

侧栏「会话锁」入口 →「钉钉通知」：

| 控件 | 说明 |
| --- | --- |
| 启用钉钉通知 | 打开/关闭完成通知；锁定功能不依赖它。 |
| 钉钉机器人 access_token | 粘贴钉钉群机器人 webhook 里 `access_token=...` 的值。它只保存在本机插件数据目录，绝不会回传浏览器（界面只显示“已设置”与末 4 位）。留空保存表示保留现有 token；点「清除」可删除。 |
| 保存 | 把设置存到本机。 |
| 发送测试消息 | 立即发一条 `[+] ` 测试消息；未配置 token 时禁用，结果在页面内提示。 |

完成消息只会在被锁定的会话结束时发送（跳过不会发送）。消息以 `[+] ` 开头，便于钉钉侧筛选。

| 设置项 | 默认值 | 单位 | 说明 |
| --- | ---: | ---: | --- |
| `notifications.dingtalkEnabled` | 关 | — | 被锁定的会话完成时向钉钉发送完成消息；锁定功能不依赖它。 |
| `notifications.dingtalkToken` | （未设置） | — | 钉钉群机器人 access_token。只保存在本机插件数据目录；浏览器只看到“已设置”与末 4 位。 |

## 跳过

点击遮罩上的「跳过」立即解锁。跳过**完全不会提醒**——没有电脑通知、没有页面横幅、也不会发送
钉钉消息；当前会话会继续运行，遮罩只是不再挡住界面。

## 完成提醒

当锁定**自动**解除时（会话及其全部子代理都已完成），即使没有配置钉钉，插件也会在本机提醒你：

- 一条**电脑通知**「会话已完成」，包含会话标题与用时分钟数；点击通知回到 DSH。它是
  **best-effort**：如果浏览器无法显示通知（权限被拒绝或环境不支持），会静默跳过；
- 页面内一条约 5 秒的**横幅**「会话已完成 · <标题>」（页面可见时总会显示，自动消失、不阻塞
  操作）。

提醒完全在本机进行：不含钉钉 token 或消息内容，也不会产生额外网络请求。跳过解锁不会出现提醒。

## 隐私

- 钉钉机器人 token 保存在本机
  `$DSH_HOME/plugin-data/dsh-deep-focus/settings.json`，不会出现在浏览器状态里（只显示
  “已设置”和末 4 位），也不会被上传到别处——只有在你配置并触发完成/测试消息时才会发往钉钉
  webhook。
- 唯一的网络请求是向 `oapi.dingtalk.com` 发送这些消息。没有遥测、没有账号、没有分析、没有
  后台采样。
- 本机完成通知与页面横幅由浏览器渲染：只使用浏览器通知权限，内容只有会话标题与用时分钟数，
  仅在自动完成时出现（跳过时没有），不产生网络请求，也不包含钉钉 token。
- 完成消息只包含会话标题、用时分钟数和完成时间——不含消息内容、文件路径、代码或其它活动数据。

详见 [docs/privacy.md](docs/privacy.md)。

## 性能

- 宿主是事件驱动的：只响应会话/轮次事件，不启动采样进程。
- 客户端只维护一份轻量状态，用链式 `setTimeout` 轮询：锁定时 1 秒、空闲 3 秒、窗口隐藏 5 秒；
  卸载后不遗留定时器。
- 宿主失联时，遮罩在连续三次轮询失败后隐藏，避免连接异常把界面永久挡住。
- 完成通知与约 5 秒横幅复用同一次轮询状态变化；它们不额外新增定时器或网络请求，横幅会自动消失。

## 限制

- 纯插件、尽力而为：不能停止模型、终止运行、控制其它应用或强制 DSH 窗口置前；关闭 DSH 会
  结束锁定。
- “会话结束”按轮次关闭判断；模型/网络报错也会关闭本轮并解锁。
- 钉钉消息需要可用网络与有效机器人 token；未配置时产品为“锁定 + 跳过 + 本机完成提醒”。
- 本机电脑通知是 best-effort：没有浏览器通知权限（或环境不支持）时只显示页面横幅。
- token 以本地 JSON 文件保存，你的用户账户可读；请把 `plugin-data/dsh-deep-focus` 当作私有
  目录。

## FAQ

**会锁住其它会话吗？** 遮罩期间它们在遮罩之下，不可使用；被锁定的那个会话是唯一可用的。

**怎样算“完成”？** 根轮次关闭，**并且**它启动的每个子代理/子会话都空闲。只要还有子会话在
工作，遮罩就会保留。

**可以跳过吗？** 可以——「跳过」立即解锁，且不会弹电脑通知、横幅或钉钉消息。

**完成时电脑会提醒吗？** 会，自动完成解锁时会弹本机通知「会话已完成」和约 5 秒的页面横幅
（前提是浏览器允许通知）；不允许时仍会显示横幅。跳过解锁不会有任何提醒。

**为什么没看到电脑通知？** 请在浏览器/系统设置中允许 DSH 发送通知；不支持或被拒绝时会退回
页面横幅。两种情况都不联网、不涉及 token。

**为什么没收到钉钉消息？** 检查启用开关、token、机器人安全设置与网络；先点「发送测试消息」。

**token 存在哪里？** `$DSH_HOME/plugin-data/dsh-deep-focus/settings.json`（默认
`~/.dsh`）。删除该目录即可移除。

**会读我的消息吗？** 不会。它只使用会话标题与轮次事件；设置页和遮罩都拿不到消息内容。
